# Asset Policy

Assets dominate perceived fidelity.

## Resolution order

1. exact user asset
2. exact repository asset
3. authorized official/project-owned source
4. faithful crop from the supplied reference when it is a genuine asset region
5. generated replacement only with user permission
6. neutral placeholder

## Icons

Match:
- stroke vs fill
- stroke width
- optical size
- internal padding/viewBox
- corner language

Do not silently replace distinctive icons with “close enough” icon-library alternatives.

## Images

Match:
- identity
- aspect ratio
- crop/focal point
- object-fit / object-position
- mini-program image mode
- clipping
- overlays

## Fonts

Prefer exact font files already supplied/owned by the project. If unavailable, use a metrically similar fallback and disclose the limitation.

Wrong fonts alter:
- line breaks
- baseline
- button width
- card height
- perceived weight
