# Skill Self-Improvement

Do not let the skill rewrite itself after every task. Improve it through evidence.

After difficult tasks, record only reusable lessons:

- reference/task class
- recurring failure pattern
- root cause that was confirmed
- fix that measurably improved fidelity
- environment/platform caveat

Promote a lesson into `references/` only when it recurs across tasks or is strongly generalizable. Keep project-specific quirks in the project, not in the global skill.

Benchmark any new rule/tool change against several UI categories before claiming it improves the skill.
