# Changelog

## v3 (2026-08-23) — Visual Replica Skill Pro

Rebuilt as a pure expert-workflow skill. The repo now ships the methodology-first
`visual-replica-skill-pro` package (SKILL.md + references + templates + learning).

- Role-based workflow: senior visual frontend engineer behavior
- Task-type classification (existing project / screenshot-only / multi-reference / responsive)
- Classified visual diagnosis (global offset / vertical drift / typography / component)
- Ordered implementation discipline (viewport → macro → components → details)
- Iteration learning loop (Problem → Hypothesis → Change → Result)
- Quality gates: visual + engineering + validation
- Continuous improvement via failure-log ledger
